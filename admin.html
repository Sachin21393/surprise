      Publishing and phone setup
      1. Finish every memory and click Download website ZIP.
      2. Extract the ZIP. Upload its contents to the root of a GitHub repository, replacing matching files.
      3. In GitHub, choose Settings → Pages → Deploy from a branch → main → / (root).
      4. Open your GitHub Pages URL on your phone. Add it to the Home Screen from Safari’s Share menu or Chrome’s Install menu.
      5. Read in landscape. If your phone won’t rotate automatically, turn it sideways and disable rotation lock.

      The studio is a local editor, without login or a server. It cannot modify the deployed book until you export and publish. GitHub Pages publishes your book and media as public files.
